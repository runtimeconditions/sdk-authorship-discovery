# Accepted AWS Python maintenance evidence

This directory retains accepted historical maintenance reports. Each release directory should contain the runner's `run.yaml` and `report.md`, including immutable upstream commits, experiment and extension revisions, classification, diagnostics, artifact digests, and the human review record.

Generated mappings, wheels, source checkouts, and verification environments are intentionally excluded. They are reproducible from the recorded inputs and are retained as workflow artifacts only when useful for diagnosis.
